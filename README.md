# Talos (塔罗斯) 🤖

> AI Agent Framework - 智能管家底层框架（多语言实现）

**名字来源**：希腊神话中的青铜自动巨人塔罗斯（Talos），每天绕克里特岛巡逻，守护岛屿免受入侵。象征着自动化、忠诚、坚固的守护者。

---

## 项目定位

Talos 是一个 AI 智能管家底层框架，为上层应用（如贾维斯 Jarvis）提供：

- **感知层**：多模态输入处理、环境理解、事件监听
- **认知层**：记忆系统、推理引擎、决策系统
- **执行层**：工具调用、多 Agent 协作、输出通道
- **元认知层**：自我监控、持续学习

## 用户界面

Talos提供了多种用户交互界面：

### 终端用户界面 (TUI)
- 使用`cargo run -p talos-ui-tui`运行
- 丰富的键盘导航支持
- 支持多面板视图（聊天、历史、工具、设置）

### API接口
- REST API支持
- WebSocket实时通信
- 适用于与其他应用集成

### 其他语言实现计划
- 图形用户界面 (GUI) - 计划中
- 移动端应用 - 计划中

| 实现 | 语言 | 状态 | 说明 |
|------|------|------|------|
| **talos-rs** | Rust | 🚧 开发中 | 系统级性能，内存安全，推荐用于生产环境 |
| **talos-py** | Python | 📋 计划中 | 快速原型，AI 生态集成 |
| **talos-go** | Go | 📋 计划中 | 高并发，云原生部署 |
| **talos-js** | TypeScript/Node.js | 📋 计划中 | Web 集成，快速开发 |

---

## 为什么多语言？

- **Rust**：核心基础设施，性能敏感场景
- **Python**：AI/ML 模型集成，快速实验
- **Go**：微服务部署，云原生
- **TypeScript**：前端/Web 集成

不同语言可以混合部署，通过 **gRPC** 或 **消息队列** 通信。

## 快速开始

### Rust 实现

```bash
cd talos-rs

# 构建
cargo build

# 运行测试
cargo test

# 运行示例
cargo run --example basic
```

### 其他语言实现

待开发...

### TUI使用示例
```bash
# 启动TUI界面
cd talos/talos-rs
cargo run -p talos-ui-tui

# 使用网关模式连接到远程服务器
cargo run -p talos-ui-tui -- --gateway
```
