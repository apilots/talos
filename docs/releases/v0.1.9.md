# Talos v0.1.9

## Highlights

- Added shared Computers and distributed Worker execution across management hosts.
- Added account data synchronization and cross-host continuation of idle sessions.
- Licensed Talos under Apache 2.0 and included license notices in product distributions.

## New Features

- **computers:** manage local and remote Computers, enroll Desktop's embedded Worker after sign-in, and bind workspaces and sessions to their Computer.
- **agent:** add distributed Worker execution, outbound hub connections, and callbacks routed through the coordinating management host.
- **sync:** synchronize account data across management hosts with persisted sharing choices and account isolation.

## Bug Fixes

- **worker:** drain registration and unregister before closing the Direct listener during shutdown.
- **computers:** correct admission cleanup, connection availability, and workspace UI regressions.
- **chat:** restore anonymous embedded TUI operation and load complete history before incremental session events.
- **agent:** preserve cancellation settlement and admitted Worker routes for OAuth and resource callbacks.
- **sandbox:** mask denied files on Linux and use explicit native runtime inputs in sandbox tests.
- **ui:** stabilize sidebar focus and wait for settings navigation.
- **upgrade:** repair pre-0.1.8 history artifacts and clean completed migration artifacts.

## Documentation

- Clarify distributed execution, Computer ownership, and synchronization contracts.
- Archive implemented designs and mark superseded Computer UI acceptance as historical.

## Build and CI

- Include Apache 2.0 license notices and the Linux sandbox launcher in the applicable product packages and images.
- Run one shared source gate for release candidates and tags, with explicit build prerequisites and one validated dependency graph per publication.
- Verify real Server/TUI packages and native TUI installation before publication.
- Publish product artifacts and multi-architecture Server/Worker images from the Talos source repository; preserve Markdown in annotated tags.
- Improve PR check scoping, external contributor gates, and E2E failure diagnostics.

## Tests

- Add multi-node Worker coordination and Computer acceptance coverage.
- Stabilize transport, settlement, browser cleanup, timeline event, and installer fixtures.

## Maintenance

- Align release stabilization and publication lifecycle checks.

## Validation

- Rust workspace checks passed with 1,584 tests; 10 tests remained skipped by their existing configuration.
- Frontend lint, type checking, Web/Desktop builds, repository checks, and 523 tests passed; two opt-in integration tests remained skipped by their existing configuration.
- All eight product targets, four native TUI installation targets, and Server/Worker images for both Linux architectures passed the hosted release gate.
- Public release asset checksums, package license contents, installer acceptance, and anonymous image manifest verification passed.
